Acoustic Masking Simulator

연구 및 평가 방법론 (Methodology)

본 시뮬레이터는 기숙사 야간 소음이 수면 질과 기상 직후 인지 기능에 미치는 영향을 확인하기 위해 설계된 연구 기반 도구입니다. 고등학교 2학년 기숙사 학생 6명을 대상으로 한 컬러 노이즈 실험의 방법론과 결과를 함께 제시합니다.

1. 객관적 인지 회복도 산출 알고리즘 (SQS)

수면 직후 피험자의 전두엽 인지 자원 회복 정도를 정량적으로 평가하기 위해 자체 개발한 Python 기반 테스트 구조를 브라우저 환경으로 구현했습니다.

- 반응 기민성: 무작위 시각 자극에 대한 반응 속도 측정

- 작업 기억력: 7자리 난수 2초 노출 후 완전 소거, 단기 기억 정확도 측정

- 순간 연산력: 제한 시간 11초 내 복합 연산 정답률 측정

\[ SQS = 0.4S_{\mathrm{react}} + 0.3S_{\mathrm{mem}} + 0.3S_{\mathrm{calc}} \]

2. 반응 점수 산출 공식

반응 속도는 총 5회 측정한 평균 반응 시간 \(t\)를 기준으로 계산합니다. 기준 반응 시간은 0.22초로 두고, 지연 시간이 길어질수록 점수를 감점합니다.

\[ S_{\mathrm{react}} = \max\left(0,\ 100 - (t - 0.22)\times350\right) \]

3. 주관적 수면 척도 검증

객관적 지표의 맹점을 보완하기 위해 주관적 수면 설문을 함께 활용했습니다. 설문은 15문항, 4점 척도로 구성되며 총점은 15~60점 범위입니다.

- 수면 양상: 입면, 각성, 수면 유지 상태

- 수면 결과: 기상 후 피로감, 집중 준비도

- 수면 저해: 소음 인식, 방해감, 환경 안정성

\[ Q_{\mathrm{sleep}} = \sum_{k=1}^{15} q_k,\quad q_k \in \{1,2,3,4\} \]

4. Custom 노이즈 믹싱 방식

연구용 Custom 노이즈는 기숙사 소음 분석 결과와 1차 실험 결과를 동시에 반영하여 설계했습니다.

- Base Layer: 저주파 충격음 차단 효과가 가장 높았던 Brown Noise

- Enhancement Layer: 작업 기억력 지표에서 강점을 보인 Pink Noise

- Defense Layer: FFT 분석에서 확인된 80~120Hz 저주파 대역 대응 필터

\[ L_{\mathrm{total}} = 10\log_{10}\left(\sum_{i=1}^{n}10^{L_i/10}\right) \] \[ 45\mathrm{dB} \approx 10\log_{10} \left( 10^{42.5/10} +10^{38.4/10} +10^{37.5/10} \right) \] \[ \mathrm{Brown}:42.5\mathrm{dB},\quad \mathrm{Pink}:38.4\mathrm{dB},\quad \mathrm{Defense}:37.5\mathrm{dB} \]

5. 개인 최적화 알고리즘

브라우저 내 개인 최적화 탭에서는 각 노이즈 조건의 SQS와 주관적 수면 점수를 직접 측정하고, 이를 기반으로 개인 맞춤형 믹싱 비율을 계산합니다.

- SQS는 100점 만점으로 계산

- 주관적 수면 점수는 60점 만점이므로 100점 기준으로 환산

- 환산 합산 점수를 제곱하여 변별력을 높인 뒤 비율을 산출

\[ C_i = SQS_i + Q_i \times \frac{100}{60} \] \[ W_i = C_i^2 \] \[ R_i = \frac{W_i}{\sum_{j=1}^{4}W_j}\times100 \]

6. Custom 노이즈 다운로드 방식

개인 최적화 결과로 계산된 \(R_i\) 값을 이용하여 White, Pink, Brown, Green 레이어를 합성합니다. 다운로드된 파일은 자기 전 반복 재생하여 실제 수면 환경에서 사용할 수 있습니다.

- 1분, 5분, 10분, 30분 길이 선택 가능

- 시작과 끝에는 부드러운 페이드 인/아웃 적용

- 과도한 음량 증가를 방지하기 위해 최종 신호는 내부적으로 정규화

\[ x_{\mathrm{custom}}(t) = r_wx_w(t) + r_px_p(t) + r_bx_b(t) + r_gx_g(t) \] \[ r_i = \frac{R_i}{\sum R_i} \]

7. 고등학교 2학년 기숙사 학생(N=6) 실험 결과 요약

용인시 소재 기숙사에 거주하는 고등학교 2학년 학생 6명을 대상으로 백색, 그린, 핑크, 브라운 노이즈 조건을 비교하였다. 기숙사 야간 소음을 FFT로 분석한 결과, 방문 개폐 진동과 복도 보행음에 해당하는 80~120Hz 저주파 대역에서 주요 피크가 관찰되었으며, 이 대역을 효과적으로 마스킹하는 브라운 노이즈 조건에서 객관적 SQS와 주관적 수면 점수가 가장 높게 나타났다.

작용 원리 및 타겟

가청 주파수 전 대역에 걸쳐 균일한 전력 스펙트럼 밀도를 가집니다. 특정 대역에 편중되지 않아 복잡하고 광범위한 환경 소음을 전체적으로 은폐하는 데 사용됩니다.

물리적 파동 특성

모든 주파수 대역의 에너지가 동일하게 섞여 있어, 시간 영역에서는 매우 불규칙하고 뾰족한 진폭을 형성하며, 주파수 영역에서는 평탄한 그래프를 그립니다.
